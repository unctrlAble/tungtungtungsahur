# Privacy Policy
Triplet Bot is designed with privacy in mind and operates with minimal data handling:

## Data We Process:

Discord User IDs: Processed in real-time when members react to the verification message to assign the Verified role and remove the Unverified role.

Guild/Server IDs & Channel IDs: Processed to identify and set permissions for the #verify channel.

## Data Storage:

No Persistent Database: Triplet Bot does not store any user IDs, messages, IP addresses, or personal information on external servers or databases. All actions are handled in-memory and through Discord's API.

## Data Sharing:

No user or server data is ever sold, rented, or shared with third parties.

## Data Removal:

Because no personal data is stored, removing the bot from your server or leaving a server automatically clears all active interaction contexts.
